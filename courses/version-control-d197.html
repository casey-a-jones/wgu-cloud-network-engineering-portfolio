Current Hands-On Project

This Portfolio Repository

I am using this portfolio itself as a live version-control project during D197. Instead of practicing only in disposable repositories, I am applying Git concepts to a real website that is stored on GitHub and automatically deployed through AWS Amplify.

Current workflow:

  • Maintain a local Git repository in PyCharm on Linux
  • Use GitHub as the remote repository
  • Synchronize remote changes with git fetch and git pull
  • Create feature branches for website updates
  • Edit project files in PyCharm
  • Review changes with git status and git diff
  • Stage changes with git add
  • Create descriptive commits
  • Merge approved work into main
  • Push updates to GitHub
  • Use AWS Amplify to deploy the updated site

Notes & Reflections

One of the most useful parts of this course is seeing Git operate on a real project. The difference between an untracked file, a modified file, and a staged file is much clearer when those states represent actual portfolio changes rather than isolated examples.
