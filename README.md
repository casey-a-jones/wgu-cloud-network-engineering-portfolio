# WGU Cloud & Network Engineering Portfolio

This repository contains my course-by-course portfolio for the B.S. in Cloud and Network Engineering with an AWS concentration at Western Governors University.

## Purpose

The purpose of this portfolio is to document my learning progress, hands-on projects, labs, notes, and reflections as I build skills in cloud infrastructure, networking, Linux, cybersecurity, IT operations, troubleshooting, and AWS.

## Portfolio Structure

Each WGU course will have its own dedicated portfolio section or page.

Each course section will include:

- Course overview
- Personal learning goal
- Key concepts
- Applied previous coursework
- Projects
- Labs / practice work
- Notes and reflections
- Cloud/network engineering connection
- Employer-ready summary

## Tools Used

- HTML

## Deployment

This website is hosted with AWS Amplify. GitHub is the source of truth, and Amplify automatically publishes updates from the repository.

The portfolio now includes a refreshed visual system, a Certifications page, shared JavaScript for theme handling, and multiple distinct selectable theme designs.

Toon Sketch is now the default theme. The shared `script.js` stores the selected theme in `localStorage` and normalizes the theme filename so the selection persists correctly between root pages and course pages inside the `courses/` folder.
